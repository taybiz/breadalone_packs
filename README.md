# breadalone_packs

**The pack source for the Breadalone app.** A curated, developer-friendly collection of scripture packs — each a single JSON file a client downloads to read a whole Bible version offline.

This repo is **the kit**: the built packs (committed, not gitignored) *and* the raw source texts they were built from, so everything is reproducible and self-contained.

> **Where this lives in the product.** Breadalone ships a set of packs bundled in the app binary. This repo is the *pack source* those come from — and it's designed so that, in the future, the app can treat *any* git repo as an additional pack source (see [Pack sources — the roadmap](#pack-sources--the-roadmap)).

---

## What is a pack?

A **pack** is the complete text of one Bible version in a compact JSON format. One file = one version. It is **text**, not binary — plain UTF-8 JSON that is cheap to serve, cache, and diff.

```
packs/
  versions.json   # the catalog — lists every version this source provides
  kjv.json        # King James Version
  asv.json        # American Standard Version
  web.json        # World English Bible
  ...             # 30 total
```

### The catalog (`versions.json`)

The single entry point. A client reads this first, learns what's available, then fetches the pack files it wants.

```json
{
  "versions": [
    {
      "id": "kjv",
      "name": "King James Version",
      "abbr": "KJV",
      "language": "English",
      "languageCode": "en",
      "canon": "protestant",
      "verseCount": 31102,
      "chapterCount": 1189,
      "bookCount": 66,
      "packBytes": 4240684,
      "source": "eBible.org · public domain (1611/1769)",
      "year": 1769,
      "original": false,
      "bundled": true,
      "notes": "..."
    }
  ]
}
```

| Field | Meaning |
|---|---|
| `id` | Stable pack identifier; also the filename `<id>.json` |
| `bundled` | `true` = shipped inside the app binary; `false` = downloadable on demand |
| `canon` | `protestant`, `catholic`, `orthodox`, or `jewish` |
| `original` | `true` if this is an original-language version (Hebrew/Greek) |
| `source` / `year` | Human-read provenance, shown in the app's Settings |

### Pack file format

See [FORMAT.md](FORMAT.md) for the full schema. In short, `format: 1` with a version header and a compact `books → chapters → verses` tree, plus optional per-chapter `headings` (e.g. the Psalms "BOOK I–V" dividers).

## Add or update a pack

Packs are generated by `tools/bible_ingest` in the **breadalone app repo** — that tool is the single source of truth for turning raw scripture text into pack JSON. This repo is the *artifact* (the committed packs + sources), kept deliberately free of a duplicated builder.

To (re)generate packs:

```bash
# in the breadalone app repository
cd <breadalone>
dart run tools/bible_ingest/bin/bible_ingest.dart --out <path>
```

Raw sources live here in [`sources/`](sources/PROVENANCE.md). Only **public-domain or freely redistributable** texts are used — no copyrighted translations.

---

## Consuming packs

A pack source exposes exactly two things a client needs:

1. `versions.json` — the catalog.
2. `<id>.json` for each version — the pack.

That's the whole contract. Fetch the catalog, pick versions, fetch their packs, cache them.

## Pack sources — the roadmap

**Status: design context, not yet built.** Today the app reads packs bundled in its binary. The forward design lets the app configure **multiple git repos as pack sources**, applied in order:

- **Canon source** — this repo (built by the app's author, so it's the reference for book/chapter structure).
- **Overlay / tertiary sources** — anyone can author their own pack source (including a *copyrighted* translation, published under their own terms) and layer it *over* the canon. Because packs are plain text JSON keyed by stable book/chapter/verse identifiers, an overlay can add a version or replace a canon one without forking or editing the canon repo.

Implementation of *that* is app-side work — the pack format and the `versions.json` contract above are all a third party needs to build a compatible source.
