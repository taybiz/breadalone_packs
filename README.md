# breadalone_packs

**The pack source for the Breadalone app.** A curated, developer-friendly collection of
scripture packs — each a single JSON file a client downloads to read a whole Bible version
offline.

This repo is **the kit**: the built packs (committed) *and* the raw source texts they were
built from — reproducible and self-contained. Today the app ships packs bundled in its binary;
the forward design treats any git repo as an additional pack source — see
[`docs/pack-sources-roadmap.md`](docs/pack-sources-roadmap.md).

## What is a pack?

A **pack** is the complete text of one Bible version in a compact JSON format: one file, one
version, plain UTF-8 — cheap to serve, cache, and diff. `packs/versions.json` is the catalog a
client reads first; `packs/<id>.json` is each version; `sources/` holds the raw texts they
were built from; `schema/` holds the JSON Schema contracts. Field meanings and the pack file
schema: [`docs/catalog-format.md`](docs/catalog-format.md), [`FORMAT.md`](FORMAT.md).

## Add or update a pack

Packs are generated by `tools/bible_ingest` in the **breadalone app repo** (single source of
truth for text → pack JSON); this repo stays the *artifact*, free of a duplicated builder:

```bash
# in the breadalone app repository
dart run tools/bible_ingest/bin/bible_ingest.dart --out <path>
```

Raw sources live in [`sources/`](sources/PROVENANCE.md) — public domain or freely
redistributable only, no copyrighted translations. `tools/validate.py` is the local/CI
validator over the whole tree.
